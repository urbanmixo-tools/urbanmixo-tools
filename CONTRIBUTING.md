# Contributing to Urban Mixo

Thank you for your interest in contributing to the Urban Mixo computational suite. 

To maintain our industry-leading **100/100 Core Web Vitals** performance and privacy standards, all contributions must adhere to our strict architectural principles.

## The 3 Golden Architectural Rules

Every tool and pull request in this repository must satisfy three core rules:

1. **Zero Runtime Dependencies:** No external npm packages, no heavy frameworks, and no external CDN scripts. Everything must run on pure, semantic HTML5, modern CSS, and vanilla JavaScript.
2. **100% Client-Side Execution:** Computation must happen exclusively in the user's browser memory. Under no circumstances should user inputs be transmitted to external servers or logged remotely.
3. **Institutional Mathematical Backing:** All equations must cite peer-reviewed academic literature or statutory standards (e.g., NIST, WHO, DoD, FLSA, ISO 80000-2).
