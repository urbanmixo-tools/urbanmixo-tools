## 🏛️ Architecture & Core Philosophy

Urban Mixo is an open-access utility network built on the conviction that essential digital computations should be **mathematically verifiable, instant, and completely private**.

Traditional online utility portals rely heavily on server-side scraping, invasive user tracking, and ad-heavy page reloads. Urban Mixo implements a **100% client-side computing architecture**:

- **Zero-Server Processing:** Calculations execute locally inside the client's browser sandbox via vanilla JavaScript.
- **Hardware-Backed Randomness:** Cryptographic utilities utilize the native browser `window.crypto.getRandomValues()` API with rejection sampling to eliminate modulo bias.
- **Peer-Reviewed Scientific & Financial Standards:** Algorithms strictly comply with institutional guidelines, including:
  - **DoD Instruction 1308.3** (US Navy Body Fat circumference equations)
  - **Mifflin-St Jeor & Katch-McArdle** (Clinical Basal Metabolic Rate baselines)
  - **NIST SP 800-63B** (Digital identity Shannon entropy models)
  - **ISO 80000-2** (Standardized exponential and mathematical notations)
  - **US FLSA Section 7** (Statutory 40-hour overtime thresholds)

## 🔒 Security & Data Governance

Urban Mixo operates under an explicit zero-persistence mandate:

- **No Remote Ingestion:** Form inputs (salaries, medical circumferences, weights, source code) are never transmitted to external APIs or remote databases.
- **Sub-processor Transparency:** Hosted via Google Edge Infrastructure; DNS and SSL/TLS routed via Cloudflare. Full operational details are disclosed on our [Trust & Security page](https://www.urbanmixo.online/p/trust-and-security.html).
- **Vulnerability Reporting:** Algorithmic variances or security observations can be submitted directly to `contact@urbanmixo.online`.
